# 🇵🇹 Portuguese by Feinman

**Português Europeu — курс A1.** 12 недель европейского португальского: от алфавита до экзамена CIPLE (A1), по методу Фейнмана.

> Понял — объясни ребёнку. Не можешь объяснить — значит, не понял.
> Пробел в объяснении = следующая тема для изучения.

## Что внутри

| Неделя | Тема |
|:-----:|------|
| 1 | Знакомство · Алфавит |
| 2 | Числа · Время · Семья |
| 3 | Прошлое · Места |
| 4 | Прилагательные · Еда |
| 5 | Время · Движение |
| 6 | Дом · Мебель |
| 7 | Одежда · Покупки |
| 8 | Тело · Здоровье |
| 9 | Природа · Погода |
| 10 | Модальные · Планы |
| 11 | Мнение · СМИ |
| 12 | Финал A1 · CIPLE |

В каждой неделе есть план, словарь с транскрипцией (IPA) и переводом, диалоги, карточки, упражнения, тест с разбором ответов и «дневник Фейнмана». В нём вы объясняете тему своими словами и получаете подсказки.

- 🔊 **Озвучка.** Нажмите на любой португальский текст (слово, пример, форму глагола, реплику), и браузер произнесёт его голосом `pt-PT` (Web Speech API).
- 📱 **PWA.** На iPhone или Android сайт можно добавить на главный экран как приложение.
- ⚡ **Без сборки и зависимостей.** Чистые HTML, CSS и JavaScript. Из сети грузятся только шрифты Google Fonts.

## Запуск

```bash
git clone https://github.com/vpresweb/Portuguese-by-Feinman.git
cd Portuguese-by-Feinman
python3 -m http.server 8000
# откройте http://localhost:8000
```

Можно просто открыть `index.html` двойным кликом. Иконка приложения (манифест) работает только при открытии через HTTP-сервер.

### Публикация на GitHub Pages

**Settings → Pages → Build and deployment → Source: Deploy from a branch**, ветка `main`, папка `/ (root)`.
Через минуту курс откроется по адресу `https://vpresweb.github.io/Portuguese-by-Feinman/`.
На бесплатном тарифе Pages работает только для публичных репозиториев.

## Структура

```
index.html             — разметка всех 12 недель
css/styles.css         — общая дизайн-система
js/core.js             — переключение недель и вкладок, озвучка speak()
js/week-01.js … 12.js  — интерактив каждой недели: карточки, тесты, упражнения
manifest.webmanifest   — манифест PWA
icons/icon.svg         — иконка приложения
```

Скрипты недель изолированы (IIFE). Наружу через `window` выходят только обработчики, которые вызываются из разметки (`W2answer`, `W2checkJ` и т. п.). Все id элементов недели имеют префикс `W<номер>`.
